MOOC: Learning Session Analysis
=================================

A series of tutorials demonstrating that TanaT is not limited to healthcare.
The same sequence analysis tools apply to any domain where ordered events
need to be compared and grouped. Here, learner interactions in an online
course (Moodle LMS).

The dataset is based on the methodology of `Saqr et al. (2024)
<https://doi.org/10.1007/978-3-031-54464-4_10>`_ and is accessible
directly via :func:`~tanat.dataset.access`.

Each script is **self-contained** and downloads the dataset automatically
on first use.
