Time Series to Sequences
========================

These tutorials show how to bridge continuous time-series data and TanaT discrete sequences
using the `Aeon <https://www.aeon-toolkit.org>`_ toolkit.

Aeon provides a rich collection of algorithms for time-series segmentation and quantization.
The resulting discrete intervals or events can then be ingested directly into a TanaT pool
for downstream analysis (clustering, metrics, visualization, etc.).
