Data Containers
===============

Build and explore *TanaT*'s core data structures: event, interval and state sequences,
as well as trajectories that combine multiple sequence types for a single individual.

The examples below illustrate the basic manipulation to the core *TanaT* objects. 
Navigating from a pool down to individual sequences and entities, attaching static
features, and composing trajectories.
For a conceptual introduction to these structures, see :doc:`../../../getting-started/concepts`.
