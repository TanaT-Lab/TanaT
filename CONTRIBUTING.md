# Contributing

Thank you for considering contributing to **TanaT**.

Contributions are managed through GitHub Issues and Pull Requests.

We welcome contributions in the following forms:

- **Bug reports**: please search existing issues before opening a new one.
- **Feature suggestions**: open an issue; include a link to the original paper if relevant.
- **Bug fixes / feature implementations**: fork, implement, and open a pull request referencing the related issue.

If you want to start small, look for issues labeled **good first issue**.

When submitting code, please think about code quality, adding proper docstrings and tests.

## Pull request workflow

The preferred workflow is to fork the main repository, develop on a branch, then open a pull request.

1. Fork the repository on GitHub.
2. Clone your fork:

   ```
   git clone git@github.com:YourLogin/tanat.git
   cd tanat
   ```

3. Create a feature branch:

   ```
   git checkout -b my-feature
   ```

4. Develop and commit your changes:  

   ```
   git add modified_files
   git commit
   ```

5. Push your branch:

   ```
   git push -u origin my-feature
   ```

6. Open a pull request from your fork.

If any of the above seems unfamiliar, please refer to the Git documentation: https://git-scm.com/documentation
